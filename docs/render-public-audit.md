# Auditoría pública de Render

Fecha de revisión: 2026-08-25.

La portada pública sirve el home nuevo, pero el encabezado sigue mostrando demasiados enlaces en línea: Home, Downloads, Vincular app, Notes, Issues, FAQ, Reportar, Privacy, Entrar y selector de idioma. En un viewport de aproximadamente 900 px el header queda muy comprimido y compite con el hero.

El footer público actual únicamente muestra `© 2026 Influent OS Engineering. Crafted by JesusQuijada34.`; no incluye un avatar/logo de GitHub, el nombre visible ni el handle enlazado, y tampoco ofrece cierre de sesión.

El home visible todavía mezcla textos en español e inglés cuando la URL usa `lang=en`: el copy del hero aparece en inglés, pero la narrativa, el indicador de scroll y las escenas permanecen en español. El bloque de capacidades todavía menciona Windows, Linux y Android; se debe retirar cualquier referencia a Termux y separar claramente las ediciones descargables.

El hero visual funciona y la mini película está presente, pero el sitio necesita un menú colapsado para escritorio pequeño y móvil, un footer de identidad más completo y una selección de edición más explícita en descarga móvil.
